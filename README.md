# integration-observability

Observable-first integration patterns.

This repo is a collection of templates and conventions for making integrations debuggable:
- Correlation IDs
- Structured logs
- Metrics per workflow
- Dashboards & alert thresholds
- Postmortems and incident checklists

## Structure
- `docs/` — principles, log schema, metrics schema
- `templates/` — drop-in snippets and starter configs
